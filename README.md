## Important
Le site utilise volontairement des noms de fichiers fixes. Cela te permet de remplacer les photos sans modifier le code : tu gardes le même nom de fichier et tu remplaces simplement l'image.

Pour tester : ouvre index.html avec Live Server dans VS Code.

## WhatsApp
Remplace TON_LIEN_WHATSAPP dans index.html/script.js par ton lien réel.

## Meta
Le site est préparé pour mesurer les leads/clics WhatsApp. Ne déclare pas un achat au simple clic. Une vraie remontée "Purchase" doit être branchée sur la confirmation réelle de commande.
